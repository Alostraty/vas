```
def find_minimum(numbers: list[int]) -> int | None:
    if len(numbers) == 0:
        return None
    min_value = numbers[0]
    index = 1
    while index < len(numbers):
        if numbers[index] < min_value:
            min_value = numbers[index]
        index = index + 1
        return min_value
data = [8, 3, 12, 5, 3, 9]
print(find_minimum(data))
```
# Варианты ответов:

###	3.Переменная index начинает работу со значения 0
###	4.Если передать пустой список, функция вернёт None
###	5.Если в списке несколько одинаковых минимальных значений, функция вернёт только первое из них
###	6.Цикл выполнит ровно len(numbers) итераций
# Правильные ответы: 1, 2, 4, 5

```
def join_with_dash(items: list[str]) -> str:
    result = ""
    position = 0
    while position < len(items):
        result = result + items[position]
        if position != len(items) - 1:
            result = result + "-"
        position = position + 1
    return result
words = ["apple", "banana", "cherry"]
print(join_with_dash(words))
```

###	5.Переменная result на последней итерации будет содержать значение "apple-banana-"
###	6.Нейтральный элемент "" позволяет корректно начать накопление с первого слова
